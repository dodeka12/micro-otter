# Runtime JSON Generated Bootstrap and Embedded Metadata Contract

**Status:** Implemented Contract
**Scope:** Phase 11 ownership migration to compile-generated `libs/runtime` artifacts

## Purpose

Define the compile-time generation contract for runtime bootstrap and embedded-metadata Python modules.

This contract enforces that:

- Runtime JSON inputs are source of truth.
- `bootstrap_setup_templates.py` and `embedded_metadata_payload.py` are generated by compile/staging.
- Runtime-owned source copies of those modules are not supported.

## Generated Artifacts

The staging pipeline generates the following files under `ports/<target>/modules/libs/runtime/`:

1. `embedded_metadata_payload.py`
  - Contains generated constants consumed by `embedded_metadata_api.py`.
  - Includes runtime identity, package summary, inventory hash payload, and optional custom-view text.

2. `bootstrap_setup_templates.py`
  - Contains generated bootstrap template builders and policy constants.
  - Includes runtime identity/custom-view constants, template builders, and summary helpers.

## Input Sources

Canonical inputs include:

- Runtime index: `src/micro_otter/nodes/device/runtime/manifest.json`
- Runtime manifest: `src/micro_otter/nodes/device/runtime/<runtime-id>/manifest.json`
- Device tools manifest: `src/micro_otter/nodes/device/tools/manifest.json`
- Node package index/manifests: `src/micro_otter/nodes/device/node_pkgs/...`
- Compile target mapping resolution metadata (board/port/mapping identity)

## Failure Categories

Generation raises categorized failures using these prefixes:

- `GENERATION_INPUT_MISSING`
- `GENERATION_INPUT_INVALID`
- `GENERATION_PATH_INVALID`

## Ownership Boundary

- Runtime directories no longer own `libs/runtime/bootstrap_setup_templates.py`.
- Runtime directories no longer own `libs/runtime/embedded_metadata_payload.py`.
- Compile-generated artifacts are mandatory for firmware builds.

## Compatibility Policy

No backward compatibility is provided for runtime-owned source versions of these modules.

- No fallback import aliases to legacy runtime-owned modules.
- Missing generated artifacts are a hard compile/staging failure.

## Validation Handoff Inputs

### Phase 12 (Versioning and Publishing)

- Include generated-module ownership in artifact lineage/versioning scope.
- Validate published firmware artifacts embed generated `libs/runtime` modules from compile output.

### Phase 13 (Testing and Rollout)

Add coverage for:

- Generated modules are always present in staged modules output.
- Generated templates module is self-contained (no legacy payload import fallback).
- Runtime manifests do not include runtime-owned bootstrap/metadata module paths.
- Generation diagnostics emit categorized errors for missing/invalid inputs.
