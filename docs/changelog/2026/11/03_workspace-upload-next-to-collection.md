# Changes since version 1.26.0

## Changes
- **Upload button moved next to the collection selector** — the main toolbar's upload
  (deploy / sync) quick action now sits directly after the graph collection dropdown instead of
  in the right-hand button group, so the selected collection and the action that uploads it read
  as one unit. Undo/redo, the version/target readout and the language switcher keep their
  positions.
